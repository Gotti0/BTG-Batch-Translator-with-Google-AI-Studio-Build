# Gemini Batch API 파이프라인 제거 계획

## 1. 개요 및 목표
애플리케이션에서 비동기 대량 처리 방식인 **Gemini Batch API 기본 모드**와 **Gemini Batch API 무결성 모드** 두 가지 파이프라인을 완전히 제거합니다. 기존의 실시간 번역 파이프라인(**기본 모드**, **무결성 모드**, **EPUB 번역 모드**)과 스냅샷·용어집·검수 기능은 기존과 동일하게 유지하여 사용자 인터페이스와 코드베이스를 단순화합니다.

---

## 2. 아키텍처 변경 다이어그램

```
[변경 전: 4가지 텍스트 번역 모드]
번역 화면 ──┬── 실시간 기본 모드 (ChunkService → 실시간 워커 병렬 호출)
            ├── 실시간 무결성 모드 (TextNodeService + EpubChunkService → JSON 스키마 실시간 호출)
            ├── [제거] Gemini Batch API 기본 모드 (InlinedRequest 조립 → 비동기 배치 작업 생성/폴링)
            └── [제거] Gemini Batch API 무결성 모드 (JSON 스키마 InlinedRequest → 비동기 배치 작업 생성/폴링)

[변경 후: 2가지 실시간 텍스트 번역 모드 + EPUB 모드]
번역 화면 ──┬── 기본 모드 (일반 텍스트 청크 분할 → 실시간 병렬 번역 및 스트리밍/재시도)
            └── 무결성 모드 (줄 단위 ID 부여 및 JSON 스키마 강제 → 줄 누락 방지 및 자동 보완)
```

---

## 3. 세부 제거 및 정리 범위

### 3.1 번역 화면 및 UI 컴포넌트 정리
- **번역 방식 선택 옵션 축소**: 번역 설정 패널의 4가지 라디오 선택지 중 `Gemini Batch API (기본 모드)`와 `Gemini Batch API (무결성 모드)` 두 항목을 제거하고, 실시간 `기본 모드`와 `무결성 모드` 2가지만 표시합니다.
- **배치 작업 관리 패널 제거**: 배치 모드 선택 시 또는 활성 배치 작업이 있을 때 표시되던 전용 배치 작업 관리 UI(작업 ID 입력 불러오기, Google 서버 목록 조회, 상태 새로고침, 결과 가져오기, 작업 취소 패널)를 제거합니다.
- **실행 버튼 문구 단순화**: 번역 시작 버튼에서 배치 작업 생성 분기 문구(`배치 작업 생성 (50% 할인)`)를 제거하고 실시간 번역 시작 문구로 통일합니다.

### 3.2 상태 관리 및 번역 실행 훅 정리
- **번역 스토어 상태 정리**: 활성 배치 작업 정보 상태와 브라우저 로컬 스토리지 연동 로직을 제거합니다.
- **번역 실행 훅 단순화**:
  - 번역 시작 함수에서 배치 모드 분기(배치 작업 생성 호출 및 완료 대기 처리)를 제거합니다.
  - 배치 상태 조회, 배치 결과 수거 및 반영, 배치 작업 취소, 작업 ID 수동 불러오기, 서버 배치 목록 조회 콜백 함수를 모두 제거합니다.

### 3.3 번역 서비스 및 로컬 저장소 정리
- **번역 서비스 배치 메서드 제거**:
  - 배치 요청 배열 조립 및 배치 작업 생성 메서드 제거
  - 배치 작업 상태 확인, 취소, 목록 조회 메서드 제거
  - 완료된 배치 응답 파싱 및 청크/줄 단위 재조립 메서드 제거
- **배치 작업 로컬 저장소 제거**: 브라우저 스토리지에 배치 작업 메타데이터와 원본 청크 매핑 데이터를 보관하던 전용 저장소 모듈과 관련 단위 테스트를 제거합니다.

### 3.4 타입 정의 및 스냅샷 호환성 정리
- **번역 모드 타입 축소**: 번역 모드 타입을 실시간 `기본 모드`와 `무결성 모드` 두 가지로 좁히고, 배치 작업 정보 인터페이스를 제거합니다.
- **스냅샷 처리 단순화**: 스냅샷 생성, 복원, 보관함 목록 표시에서 배치 모드 분기를 정리하되, 기존에 저장된 스냅샷을 불러올 때도 안전하게 기본/무결성 모드로 호환되도록 유지합니다.
